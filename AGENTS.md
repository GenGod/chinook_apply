# AGENTS.md — Обязательные правила разработки (canada_job_search)

Этот файл — контракт для любого AI-агента, работающего с репозиторием.
Иерархия документов: **CONSTITUTION.md → PROCESS.md → AGENTS.md → DESIGN.md → specs/**.
Конституция и процесс описывают ЧТО нельзя и КАК идёт работа; этот файл — КАКИМИ инструментами.
Проект и архитектура описаны в [DESIGN.md](./DESIGN.md). Правила ниже обязательны.

## Правила пайплайна (дополняют DESIGN.md раздел 6)

0. **Модели (PROCESS.md §2).** Решения (brainstorm, спеки, планы, ревью, security) — только Архитектор GLM-5.3. Код и тесты по плану — Имплементатор GLM-5.3-flash; он не принимает архитектурных решений — эскалация, не импровизация.
1. **Спека прежде кода.** Ни одной строчки прод-кода без принятой спеки в `specs/` и плана (`superpowers:writing-plans`).
2. **Только TDD.** Порядок внутри инкремента: brainstorming → план → красные тесты → green → refactor (LSP-чистота) → arch-lint → E2E + снапшоты до/после → security-аудит → verification-before-completion → merge. Прод-код без предшествующего красного теста запрещён; каждый багфикс начинается с воспроизводящего красного теста, случай остаётся в сьюте.
3. **Документация прежде зависимости.** Новый пакет/API — сначала `context7`, потом код. Версии сверять с `STACK.md`; стек менять только с approve PO.
4. **UI не пишется без дизайна.** Экран сначала проходит через `superdesign` (варианты + выбор), затем `frontend-design` (вёрстка), затем проверка через `chrome-devtools` и Playwright-снапшоты до/после (git-lfs) — на каждую итерацию, включая не-UI-шные (регрессионное отсутствие диффа).
5. **Машинные гейты прежде ручных.** Всё, что автоматизируется (линтеры, типы, тесты, arch-lint, secret-scan, visual diff), — blocking-гейты CI; ручными остаются только продуктовые решения PO (PROCESS.md §5).
6. **Security-гейт непроходим формально.** В PR-описании инкремента — вывод `claude-security` аудита (что проверено, что найдено, что исправлено). Без него инкремент не считается завершённым.
7. **Метрики — часть DoD.** Каждый инкремент, затрагивающий LLM-пайплайн, обновляет отчёт по токенам/стоимости на golden-set с разбивкой по типу модели; деградация алертится.
8. **Никаких секретов в git.** Ключи — только `.env`/docker secrets; аудит на каждом инкременте.

## Отчётность по инкременту

Каждый завершённый инкремент оставляет запись в `specs/notes/S<N>-report.md`:
- что сделано, DoD-чеклист спеки (выполнено/нет);
- результат тестов (unit/E2E/снапшоты) — с цифрами;
- security-аудит (кратко);
- расход токенов на golden-set, если затронут LLM.
