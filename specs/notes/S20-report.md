# S20 Report — Предпросмотр вакансии перед уходом к внешнему провайдеру

Дата: 2026-09-20 · Спека: `specs/S20-job-preview.md` v1.0 (accepted PO) · Ветка: `feat/S19-province-filters` (стеком)

## Что сделано

- **Explorer** (`apps/web/app/page.tsx`): заголовок вакансии — внутренняя ссылка
  `/job/{id}` (без `_blank`); рядом компактная «↗» (`data-testid="apply-external"`)
  на `job.url` с `_blank` + `noopener noreferrer` — прямой внешний отклик из
  таблицы сохранён (контракт B-001/S1a).
- **Предпросмотр** (`apps/web/app/job/[id]/page.tsx`): обрезка 1200 снята;
  `htmlToText` — `<br>`/`</p>`/`</li>`/`</hN>` → переводы строк, прочие теги
  стрипаются, базовые entity декодируются (после стрипа — entity не создают
  тегов); рендер `white-space: pre-line`.
- **e2e-seed**: синтетическая ON-вакансия получила `raw.description` ≈1600
  символов с `<br><br>` и entity (фикстуры ≤500 — детерминированный объект
  теста полноты).
